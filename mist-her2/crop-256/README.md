# Crop-size study: 256 pixels

A smaller training crop tests local paired agreement against global image quality.

## Included evidence

We use this folder for the exported crop-size comparison and DAB example panel. Quantitative results with machine-readable provenance are listed separately in the tracking index.

## Interpretation

Use the manifest to identify train/validation/test. Original `train/` and `test/` prefixes in image IDs are release paths. Do not compare small validation galleries, selected test subsets and full-test results as if they used the same evaluation population.
